# 🌟 SinarQuran by Almer

**SinarQuran by Almer** adalah platform web modern untuk membaca, mendengarkan, dan mempelajari Al-Quran secara digital. Dilengkapi antarmuka yang bersih, responsif, dan ramah pengguna untuk memudahkan ibadah harian di mana saja.

---

## 🚀 Fitur Utama

- **📖 Baca Al-Quran Digital:** Menampilkan teks Arab yang jelas, terjemahan bahasa Indonesia, serta tafsir untuk memudahkan pemahaman ayat.
- **🎧 Audio Murrotal:** Pemutar audio qari pilihan per ayat atau per surah untuk mendengarkan lantunan ayat suci secara langsung.
- **🔍 Pencarian Cepat:** Fitur pencarian instan untuk menemukan surah, ayat, atau kata kunci tertentu dengan mudah.
- **🌙 Dark Mode / Light Mode:** Pilihan tema tampilan yang nyaman untuk mata, baik digunakan pada siang maupun malam hari.
- **📱 Desain Responsif:** Antarmuka yang dioptimalkan agar tampil sempurna di berbagai perangkat (Mobile, Tablet, Desktop).
- **🔖 Penanda (Bookmark):** Menyimpan posisi ayat terakhir yang dibaca untuk melanjutkan ibadah dengan praktis.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend:** HTML5, CSS3, JavaScript (atau sebutkan framework/library seperti React / Vue / Tailwind CSS)
- **API:** Al-Quran API / Quran.com API (untuk pengambilan data surah, teks, dan audio)
- **Deployment:** Vercel / Netlify / GitHub Pages
